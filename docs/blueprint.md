# **App Name**: Omkar's Odyssey

## Core Features:

- Interactive Bio: Interactive 'About Me' section with a profile picture display.
- CV Snapshot: Dynamic display of education, work experience, projects & publications and skills from a JSON configuration.
- Get In Touch: Contact form submission via Google Forms integration.
- Responsive Design: Responsive layout for seamless viewing across devices.
- Dynamic Welcome: AI-powered tool to personalize the introductory paragraph of the 'About Me' section, tailored to the detected interests of the viewer. Generates a rewritten bio only when engagement can be increased.

## Style Guidelines:

- Primary color: A vibrant purple (#A78BFA) to reflect creativity and technical expertise.
- Background color: Dark gray (#2D2D2D) for a modern, funky dark mode experience.
- Accent color: Electric blue (#7DF9FF) and Orange (#FF8C00) to highlight key sections and call to actions.
- Clean and modern typography optimized for readability on all devices.
- Funky and modern layout with clear sections.
- Subtle transitions and hover effects to enhance user interaction.
